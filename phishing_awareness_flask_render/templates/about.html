About this project

This is a phishing awareness simulator you can extend for training. It intentionally avoids any real phishing capabilities (no credential collection, no stealth tracking, no weaponized payloads).

Safe extension ideas

  • Add more scenarios and tailor red-flag explanations.
  • Add a “Report email” flow that teaches the correct process.
  • Add an internal admin dashboard with aggregate stats (consensual training only).
  • Integrate SSO for known trainees (still don’t collect passwords).
Use only in environments where participants have given informed consent and you have permission to run training.
